# 查证工具（AI侦探社）产品规格说明书
> 依据《查证工具产品实现手册》WaytoAGI AI切磋大会 · 1024超能Coding周末 · 郑州站
## 1. 产品定位
一个**查证工具**：用户输入一段文本或网传消息，工具自动完成全网检索、信息核对与溯源，
输出带来源的结构化**查证卡**。查证卡呈现「结论＋依据＋来源」，强调**结论有依据、来源可追溯**。
目标用户：自媒体小编、学生、普通网民、宣传岗位人员。

### 模块接口契约
| 模块 | 接口 | 入参 | 出参 |
|---|---|---|---|
| 输入 | `POST /api/verify` | `{text}` | 校验后文本 |
| 检索 | `extract_keywords()` | 待核实文本 | 关键词列表 |
| 检索 | `search()` | 关键词 | 候选来源列表 |
| 核对 | `cross_check()` | 原文＋来源 | 核对结果 |
| 分级 | `grade()` | 核对结果 | 三级结论 |
| 生成 | `build_card()` | 结论＋依据＋来源 | 查证卡数据 |
| 输出 | `GET /api/card/{id}` | 卡片ID | 页面/图片 |
## 4. 双引擎策略
手册要求「大模型 API + 搜索 API」，但赛事环境密钥不确定。采用**双引擎自适应**：
| 引擎 | 触发条件 | 能力 |
|---|---|---|
| **本地查证引擎**（默认） | 未配置密钥 | 规则化关键词提取 + 内置可追溯来源库 + 证据匹配打分 + 三级分级 |
| **大模型引擎** | 配置 `LLM_API_KEY` + `SEARCH_API_KEY` | 真实联网检索 + LLM 三段式提示词核对 |
两引擎**输出同一份查证卡数据结构**，前端无感知切换。
### 三段式提示词（大模型引擎）
1. **检索提示词**：给定待核实文本，输出核心实体与搜索关键词（1-3条）。
2. **核对提示词**：给定原文与来源列表，输出支持依据、矛盾证据及对应来源。
3. **分级提示词**：给定核对结果，输出结论（属实/不实/存疑）与理由。
## 5. 可信度分级规则
| 结论 | 判定条件 | 置信度区间 |
|---|---|---|
| **属实** | 多个可信来源一致支持原文，未发现矛盾证据 | 75-98 |
| **不实** | 多个可信来源一致否定原文，矛盾证据充分 | 75-98 |
| **存疑/信息不足** | 证据不足、来源过少、或支持与矛盾并存且无法判别 | 20-60 |
**硬约束**：分级结论必须能回指到具体依据与来源，禁止「仅给结论不给证据」。
## 6. 来源可信度评估维度
| 维度 | 评估要点 | 权重 |
|---|---|---|
| 来源性质 | 官方、权威机构、正规媒体 > 个人自媒体 | 40% |
| 发布时间 | 时效性符合事件背景者更可信 | 20% |
| 一致性 | 与多方来源一致程度越高越可信 | 25% |
| 证据链 | 能给出可核验事实与引用的来源更可信 | 15% |
来源分档：`A 权威` / `B 可靠` / `C 一般` / `D 存疑`
## 7. 冲突信息处理
当不同来源结论冲突时，**不强行二选一**，而是：
1. 并列呈现「支持证据」与「矛盾证据」两栏；
2. 标注结论为「存疑」；
3. 向用户说明分歧点；
4. 由用户结合更多信息判断。

## 9. 页面信息架构（分模块作答）
查证结果区**严格分区，互不混杂**：
1. **结论模块** — 大字结论徽章 + 置信度环形进度 + 一句话摘要
2. **依据模块** — 左「支持证据」/ 右「矛盾证据」双栏对照
3. **来源模块** — 来源卡片列表，每条含域名、时间、可信度标签、可点击链接
4. **分歧模块** — 仅当存在冲突时出现，并列说明分歧点
5. **风险模块** — 核查局限与使用建议
6. **元信息模块** — 卡片ID、核查时间、引擎、耗时、关键词
## 10. 视觉规范：查证科技风
| 要素 | 规范 |
|---|---|
| 主色 | 深空墨 `#070B14` 背景 |
| 强调色 | 查证青 `#00E5C0`（扫描/证据链） |
| 结论色 | 属实 `#22D39A` / 不实 `#FF4D6D` / 存疑 `#FFB020` |
| 质感 | 网格底纹 + 扫描线 + 玻璃拟态卡片 + 发光边框 |
| 字体 | 等宽字体用于数据/ID，无衬线用于正文 |
| 动效 | 检索时雷达扫描、证据链逐条点亮 |
## 11. 边界与异常
| 场景 | 处理 |
|---|---|
| 空输入 | 前端拦截 + 后端 400，提示补充 |
| 文本过短无实体 | 直接输出「存疑/信息不足」 |
| 检索无结果 | 不强行下结论，走存疑分支 |
| 来源冲突 | 并列呈现 + 存疑 |
| 导出失败 | 前端降级为复制文本 |
## 12. 自测用例
| 类型 | 输入样例 | 预期 |
|---|---|---|
| 基础（真实） | 常识性事实描述 | 属实 + 来源佐证 |

| 边界（不足） | 信息模糊内容 | 存疑 + 不强行下结论 |
